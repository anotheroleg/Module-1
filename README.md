# Module-1

**Что делает проект?**
Цель проекта – научиться использовать основные функции GitHub в рамках модуля №1.

**Где notebook, данные и отчёт?**
Notebook – в разделе notebooks. Данные – в папке data. Отчёт и документация – в папке docs.

**Что сделать проверяющему?**
Функциональная часть проекта – блокнот в Google Colab с названием lr01_runtime_order_Kuzmin.ipynb. Её следует открывать в Google Colab.

**Как понять, что всё работает?**
Если при нажатии "Перезапустить сеанс и выполнить весь код" (Runtime restart and run all) текстовая карточка отображается, то программа работает. Если вдруг значение переменной text_card потеряется и будет ошибка NameError, то следует воспользоваться комбинацией клавиш Shift + Enter. 

**Что не проверяется или может сломаться?**
Может потеряться значение переменной text_card. Что делать в таком случае – написано выше.

**Что было изменено и зачем?**
Основной блокнот был удалён, так как обнаружилось, что из всего блокнота сохранилась лишь одна текстовая ячейка. Блокнот восстановлен и загружен снова.
Репозиторий упорядочен с помощью папок – документы, данные и блокноты отдельно. README.md скопирован и присутствует и в папке, и на главной странице.
